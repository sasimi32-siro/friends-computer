원격 지원

아래 버튼으로 프로그램을 받아 실행해 주세요.

원격 프로그램 다운로드클릭하면 다운로드가 시작됩니다

사용 방법

  1. 위 버튼을 눌러 파일을 다운로드합니다.
  2. 다운로드한 파일을 실행(설치)합니다.
  3. 프로그램이 열리면 내 데스크탑 ID와 일회용 비밀번호가 표시됩니다.
  4. 아래 화면처럼 ID와 일회용 비밀번호를 사진으로 찍어서 보내주시면 됩니다.

이 화면의 ID와 일회용 비밀번호를 찍어서 보내주세요

⚠️ 다운로드 시 경고가 떠도 정상입니다 보안 인증이 없는 프로그램이라 브라우저가 경고를 띄우지만, 안전한 파일이니 아래대로 진행하시면 됩니다.

크롬(Chrome) — "안전하지 않은 파일" 또는 "일반적으로 다운로드되지 않는 파일" 경고가 뜨면, 경고 옆의 ▾ (또는 ⋯)를 눌러 "계속" 또는 "유지"를 선택하세요.

엣지(Edge) — "안전하게 다운로드할 수 없습니다" 경고가 뜨면, 알림 위에 마우스를 올려 ⋯를 누르고 "유지"를 선택하세요. 그다음 "자세히" → "계속 유지"를 눌러주세요.
