아래 순서대로 프로그램을 받아 실행해 주세요.
문제가 생길 시 010-8820-1904 로 연락주세요.

원격 프로그램 사이트 열기https://rustdesk.com/ko/

사용 방법

1
위 버튼을 눌러 사이트가 열리면, 파란색 「다운로드」 버튼을 눌러주세요.
파란색 다운로드 버튼을 클릭
2
다음 화면에서 Windows 칸의 「EXE」 글자를 눌러 파일을 받습니다.
x86-64 줄의 EXE 클릭 (MSI 아님)
3
다운로드한 파일을 실행합니다. (설치 창이 뜨면 그대로 설치하시면 됩니다.)
4
프로그램이 열리면 내 데스크탑 ID와 일회용 비밀번호가 표시됩니다. 아래 화면처럼 ID와 일회용 비밀번호를 사진으로 찍어서 보내주시면 됩니다.
이 화면의 ID와 일회용 비밀번호를 찍어서 전송
⚠️ 다운로드 시 경고가 떠도 정상입니다 보안 인증이 없는 프로그램이라 브라우저가 경고를 띄우지만, 안전한 파일이니 아래대로 진행하시면 됩니다.

크롬(Chrome) — "안전하지 않은 파일" 또는 "일반적으로 다운로드되지 않는 파일" 경고가 뜨면, 경고 옆의 ▾ (또는 ⋯)를 눌러 "계속" 또는 "유지"를 선택하세요.

엣지(Edge) — "안전하게 다운로드할 수 없습니다" 경고가 뜨면, 알림 위에 마우스를 올려 ⋯를 누르고 "유지"를 선택하세요. 그다음 "자세히" → "계속 유지"를 눌러주세요.
